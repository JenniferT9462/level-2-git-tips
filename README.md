# Level 2 Git Tips

A class collection of Git tips, built entirely through pull requests.

This repository is for practicing the **fork → clone → branch → commit → push → pull request** workflow.
See [CONTRIBUTING.md](CONTRIBUTING.md) for how to add your tip.

## How this works

```text
this repo → fork on GitHub → clone locally → commit → push to your fork
                                                    ↓
                                    pull request back to this repo
```

## Tips

Each tip lives in its own file in the [`tips/`](tips/) folder, so many people can
contribute at the same time without editing the same lines.
